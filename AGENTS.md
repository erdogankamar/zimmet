# AGENTS.md

Bu plugin için kanonik yapay zeka bağlamı `AI_CONTEXT.md` dosyasındadır.

Tüm ajanlar şu kurallara uymalıdır:

- Türkçe cevap ver.
- `hscdestek.com.tr` ana GLPI/deploy projesi, `zimmet` ayrı plugin projesidir.
- Plugin'in kanonik GitHub reposu `https://github.com/erdogankamar/zimmet` adresidir.
- GLPI çekirdek dosyalarına dokunma.
- Plugin dışı dosyalara açık talimat olmadan dokunma.
- Release/tag işlemlerinde `erdogankamar/zimmet` reposunu hedefle.
- Gizli token veya parola dosyalara yazma.

Ayrıntılı proje bilgisi, dosya haritası, ayarlar, doğrulama ve release akışı
için `AI_CONTEXT.md` dosyasını oku.
